# 📊 Tecboard

> Projeto desenvolvido durante os cursos de front-end da **Alura**[cite: 2]. O Tecboard é uma landing page moderna e responsiva voltada para uma plataforma de monitoramento em tempo real e alertas inteligentes para aplicações[cite: 3].

## 💻 Sobre o Projeto

A página foi estruturada utilizando HTML5 semântico e estilizada com CSS3 puro. O layout conta com uma identidade visual focada em temas escuros (*dark mode*), tipografia personalizada via `@font-face` (Poppins e Unbounded) e adaptação completa para diferentes tamanhos de tela (responsividade para desktops, tablets e dispositivos móveis).

## 🚀 Tecnologias Utilizadas

* **HTML5** — Estruturação de conteúdo e marcação semântica[cite: 3].
* **CSS3** — Estilização avançada, variáveis, seletores e design responsivo com `@media queries`[cite: 4].
* **Git e GitHub** — Controle de versão e hospedagem do código-fonte.

## 📱 Responsividade

O layout foi planejado para se adaptar perfeitamente a diferentes resoluções de tela:
* **Desktop:** Layout amplo com alinhamentos customizados e imagens em destaque.
* **Tablets (`max-width: 768px`):** Ajustes de margens e redimensionamento de elementos textuais[cite: 4].
* **Mobile (`max-width: 375px`):** Otimização de fontes do título, redimensionamento de botões de chamada para ação (*CTA*) e reajuste das imagens dos celulares[cite: 4].
